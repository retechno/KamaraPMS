# Panduan Pengguna KamaraPMS

Panduan ini untuk staf hotel yang memakai KamaraPMS setiap hari: resepsionis, petugas housekeeping, kasir, akuntan, manajer, dan administrator. Setiap halaman menjelaskan satu tugas: siapa yang mengerjakannya, kapan, apa yang perlu disiapkan, lalu langkah-langkahnya satu per satu.

Nama menu, tombol, dan kolom di panduan ini ditulis persis seperti yang tampil di layar dalam **Bahasa Indonesia**. Kalau layar Anda masih berbahasa Inggris, ganti bahasanya dulu: lihat [Mengganti bahasa dan tampilan](00-memulai/mengganti-bahasa-dan-tampilan.md).

> Gambar di panduan ini diambil dari hotel contoh, **Hotel Kamara Ubud**. Nama tamu, nomor kamar, dan harga hanyalah contoh. Menu yang Anda lihat bisa lebih sedikit, karena menu mengikuti peran Anda.
