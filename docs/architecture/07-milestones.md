# MVP Implementation Milestones (revision 3): Step 17

Each milestone is small, can be shipped on its own, and ends with green tests against real PostgreSQL. **Money and posting code (M7, M11–M13) must not start before M6 (the engine) is finished and tested.**

**Critical path:** M0 → M1 → M2 → M3 → M5 → M6 → M7 → M8 → M9 → M10 → M11 → M12 → M13. M4 (guests) can run in parallel after M2, and M14 after M13.

**Definition of done for every milestone:**
- Migrations are reversible.
- sqlc queries are scoped by `property_id` or `tenant_id`.
- Every state change writes an audit log in the same transaction.
- OpenAPI is updated.
- The race tests for that milestone pass.
